# Fleet Appearance evidence: kyPulse (2026-10-26)

Staged screenshots, capture manifests and real-browser checks for the fleet Appearance
rollout (ky-ui 0.4.0, shared source `4f83f34`). Ratings belong to the independent
Claude Opus 5.5 council; this record claims no score.

## Stages

| Stage | Source | What it shows |

Every manifest records the source commit, a SHA-256 of uncommitted source (this
directory excluded), OS, driver, fixture, capture time and each PNG's SHA-256.
`captures.csv` and `behaviour-checks.csv` are the spreadsheet form, generated by
`results.mjs` from the manifests.

## Changes

- Appearance page for every signed-in role (sidebar row, `#/appearance` in kyPulse, a tab in Base): native radio cards for Match system plus every ky-ui catalog theme. Per the owner's correction it replaces the sidebar theme selector; the sign-in page keeps its own.
- `src/theme.ts` adapts the shared catalog under the existing `ky_theme` key. Saved IDs resolve unchanged, including base `patina` (`Patina Ky (base)`, palette untouched), which stays distinct from suite `patina-ky`. Named palettes apply inline through `applyThemeVariables` and Busnes clears them. One `useTheme()` store keeps every control in sync (this fixed a same-tab desync found in testing).
- Shell from ky-ui tokens: 240px sidebar, 40px navigation and control rows, 8px radius, 15px body, 24px/600 titles without decorative accent icons, left-aligned pages, visible focus. On mobile, brand and account actions share the top row and navigation scrolls below.
- Status, Alerts and Settings titles use the shared header; the Settings Appearance card is removed (Settings links to Appearance).

## Checks

- `make ci` (tidy, gofmt/vet, race tests, 96 vitest tests including `Appearance.test.tsx`, smoke): pass on the final tree; results for the merged tree are recorded in the PR.
- Playwright `npm run test:browser` (16 tests, light/dark × 390/1280): passed on the tree before the mobile-header fix. The rerun on the final tree waits for the shared port 5391 slot; see the PR.
- `ui.spec.mjs` covers: no selector in the signed-in shell, catalog-sized cards, Match system, arrow keys and focus, persistence across reload and tabs, and Sky (light named) keeping light nav hover and selected surfaces before returning to Busnes.
- `source.patch` is the reviewable diff without the built `web/dist` bundle and vendored ky-ui.

## Known limits and open defects

- Mobile horizontal navigation does not scroll the current page into view (existing pattern), so Appearance can sit off-screen at 390px.
- Full-page captures show the sticky sidebar ending at viewport height; real scrolling keeps it pinned.
- Settings panels still carry accent-coloured section icons and boxed cards; a forms pass was not done.
- Stage 01 previews are blank: they were captured before the shared preview stylesheet existed. Stage 02 is the confirmation.
- The status fixture's fake health endpoint listens on the capture host's private LAN address (the egress guard refuses loopback; no bridge interface was up), so that address appears in the screenshots.

## Reproduce

From the repository root, after `cd web && npm ci && npm run build` and `go build -o .browser/server ./cmd/server`: `node docs/ui-fleet-2026-10-26/capture.mjs 02 after`. It runs a disposable server on 127.0.0.1:5491 with temporary SQLite data and three synthetic watched apps (ok, degraded, down).

`node docs/ui-fleet-2026-10-26/results.mjs` regenerates the CSVs. Captures use only
synthetic data in a temporary directory that the script deletes; nothing touches a
live or production instance.
